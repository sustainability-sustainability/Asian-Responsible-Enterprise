## 📊 ObjectId Format

### Valid MongoDB ObjectId:
```
675abc123def456789012345
├─ 8 chars: timestamp (4 bytes)
├─ 10 chars: random value (5 bytes)
└─ 6 chars: counter (3 bytes)
```

**Requirements:**
- Exactly 24 characters
- Only hex digits (0-9, a-f)
- Auto-generated by MongoDB or our utility

### Invalid IDs (OLD):
```
❌ "1"
❌ "2"
❌ "123"
❌ "test-id"
❌ 1734567890 (timestamp)
```
