## 🔐 Admin Access (Quick Reminder)

### Method 1: Bypass (Development)
1. **Click logo** 5 times quickly (top left)
2. **Hold** `Ctrl+Shift+D` for 3 seconds
3. **Click** "Bypass Authentication" button
4. **Access granted!** 🎉

### Method 2: Google OAuth (Production)
1. **Click logo** 5 times quickly
2. **Click** "Login with Google"
3. **Authenticate** with your Google account
4. **Access granted!** 🎉

## 💡 Pro Tips

### Development
- Use browser DevTools (F12) for debugging
- Check console for admin access hints
- All data auto-saves in dashboard
- Test on multiple browsers

### Content Management
- Images should be < 1MB for best performance
- Videos should use Cloudinary (> 5MB)
- Always preview changes before saving
- Use the bypass method for quick testing

### Deployment
- Run `node setup-production.js` for guided setup
- Test locally before deploying
- Use free tiers for small projects
- Monitor your quotas
